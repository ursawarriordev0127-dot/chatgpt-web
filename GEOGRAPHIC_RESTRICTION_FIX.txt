STEP 1: Get a Proxy
-------------------
Option A - Use existing VPN/Proxy software (Clash, V2Ray, Shadowsocks):
  ✓ Start your VPN client
  ✓ Enable HTTP proxy mode  
  ✓ Note the port number (usually 7890, 1080, or 10809)

Option B - Use commercial proxy service:
  ✓ Sign up: Brightdata, Oxylabs, Smartproxy, IPRoyal
  ✓ Get proxy credentials
  ✓ Note format: http://username:password@proxy-server:port

================================================================================

STEP 2: Configure Environment Variable
---------------------------------------
In PowerShell (Windows):

# Set proxy for current session
$env:HTTPS_PROXY = "http://127.0.0.1:7890"      # For local VPN
# OR
$env:HTTPS_PROXY = "http://user:pass@proxy.com:8080"  # For commercial proxy

# Also set HTTP_PROXY
$env:HTTP_PROXY = $env:HTTPS_PROXY

================================================================================

STEP 3: Start Server
--------------------
npm run dev

================================================================================

STEP 4: Verify It's Working
----------------------------
Check server logs for these messages:

✅ SUCCESS - You should see:
  [Proxy] Using proxy: http://...
  [Chat Request] Model: gpt-5, Using proxy: Yes

❌ PROBLEM - If you see:
  [Proxy] No proxy configured...
  [Geographic Restriction] No proxy configured!

  → Solution: Check environment variable is set
  → Run: echo $env:HTTPS_PROXY
  → Should show your proxy URL

================================================================================
                            TROUBLESHOOTING
================================================================================

PROBLEM: "No proxy configured" in logs
SOLUTION:
  1. Check: echo $env:HTTPS_PROXY
  2. If empty, set it again
  3. Restart terminal
  4. Restart server

PROBLEM: Still getting geographic restriction error
SOLUTION:
  1. Check proxy is running
  2. Test: curl -x http://127.0.0.1:7890 https://api.openai.com
  3. Ensure proxy is in supported region (US, UK, etc.)
  4. Check proxy IP: Visit ipinfo.io from proxy

PROBLEM: Connection timeout
SOLUTION:
  1. Check proxy port is correct
  2. Check firewall allows connections
  3. Try different proxy server
